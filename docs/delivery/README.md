## Демонстрация без передачи датасета

`scripts/record_delivery_demo.py` выполняет реальные команды Docker и сохраняет
stdout, exit codes и время в `terminal.json`. Берутся первые5query и полная636gallery
из фиксированных **train fold0 CSV**, без подбора картинок по результату модели.
Полная статическая gallery сохраняет смысл gallery-z порога6.6; предварительный
smoke25/25 создал валидный пустой candidates и не служит демонстрацией качества.
Исходные изображения в публичную копию и видео не включаются.

```bash
python3 scripts/record_delivery_demo.py --data-root /absolute/dataset \
  --out outputs/demo-new --image falcon-reid:public-d065
```

Запись запускает контейнер без сети, монтирует только demo-input read-only и
новый output, затем отдельным контейнером проверяет C6. Канонический `submission/`
не меняется. Маленький demo подтверждает работу интерфейса, **не качество**.

Ролик формируется `scripts/render_delivery_demo.py` из этой записи, с явной
подписью о сокращённых паузах/длинном выводе. Полный transcript сохраняется рядом.
Это демонстрация терминального прогона, не realtime GPU benchmark.

## Публикация и конфиденциальность

По решению пользователя28.09 выпускается новая чистая публичная копия, а не
открывается исходная история. В ней ранее были реквизиты доступа к внешним
датасетам; удаляющий commit не удаляет старые значения. Приватный архив сохраняется.
Не переносим private refs, переписку, ключи, данные организаторов, окружение,
служебные сведения серверов и личные локальные пути.

Публикуется только выбранный финальный bundle с прежними archive/manifest SHA,
а не вся коллекция исторических Releases. Provenance внутри пакета не меняется;
исторические private source URLs — справка о происхождении, анонимный запуск
должен зависеть только от публичного зеркала конечного bundle.

Ограничения приёмки остаются видимыми: singleton/batched confidence strict FAIL
при одинаковых проверенных IDs/решениях, неполное покрытие геометрической маски,
C4 twofold качество не равно измерению качества полного Docker-пути.

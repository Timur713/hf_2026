# Таблица скоростей

Замеры по протоколу ТЗ §7.1 и контракту C5: задержка — медиана 300 прогонов при batch=1 после 50 прогревов, FPS — лучший из batch 1, 8, 16 и 32. **Основание для решений — только замеры на A5000.** Цифры с A10 и 4090 пересчитываются по коэффициентам ниже.

Цели на A5000 — полный балл с запасом ×2: задержка ≤ 20 мс, FPS ≥ 200.

## Коэффициенты пересчёта

Коэффициенты ниже умножают замер исходной GPU, чтобы оценить A5000. Для A10 обе точки измерены одним C5-путём на model-v1.

| Замер | A10 → A5000 | 4090 → A5000 |
|---|---|---|
| задержка | **×0,440** (38,32 → 16,85 мс) | —, нет сопоставимого C5-замера |
| FPS | **×1,177** (204,8 → 241,1) | —, нет сопоставимого C5-замера |

Коэффициент 4090 не подменён отношением TFLOPS: в репозитории есть время обучения на 4090, но нет замера того же `extract()` с model-v1. Для честного коэффициента нужен один прогон `bench_extract.py` на 4090 с теми же весами и CSV.

# Результаты D065 — архив

> Этот документ описывает сентябрьский D065. Актуальный D082 и ограничения: [приёмка](d082_acceptance.md).

## Качество и порог

Два encoder и verifier оценены на train-фолдах 0 и 1. Для каждого фолда использованы модели, обученные без его автомобилей. Поиск и проверка пар воспроизведены по сохранённым эмбеддингам и логитам; метрики рассчитаны через `reid/eval/eval_local.py`. Junk одной машины и камеры удаляется до усечения списка до 10, без добора.

| Показатель | Fold 0 | Fold 1 | Среднее |
|---|---:|---:|---:|
| mAP@10 без verifier | 0.861191 | 0.837467 | 0.849329 |
| mAP@10, вес verifier 0.15 | 0.867501 | 0.837581 | **0.852541** |
| 0.7 × F1 + 0.3 × TNR, порог 6.6 | 0.964296 | 0.956645 | **0.960470** |

[Отчёт fold 0](evidence/quality_fold0.json) · [Отчёт fold 1](evidence/quality_fold1.json). В JSON сохранены параметры, метрики и SHA входов. Дампы и логиты не входят в эту поставку; порядок повторного обучения и оценки описан в [training.md](training.md).

Это результат калибровки на двух OOF-фолдах, а не независимая оценка на пяти фолдах или закрытом тесте. Повторное JPEG-сжатие кропов и полный путь чтения кадров дают различия; перенос качества и порога на полный Docker-путь отдельно не подтверждён.

## Скорость

[Исходный замер RTX A5000](evidence/a5000.json): одна GPU, драйвер 535.54.03, 8 vCPU, два финальных encoder. Таймер включает чтение с диска, декодирование JPEG, crop, resize, forward и L2. Загрузка модели, поиск и verifier в этот таймер не входят.

- 50 прогревов и 300 синхронизированных измерений batch=1: медиана **24.884 мс**.
- Не менее 10 секунд на batch 1/8/16/32: лучший throughput **102.674 FPS**, batch=32.
- Размер всех весов, включая verifier: **788 647 632 байта**.

Команда для нового замера из корня репозитория после установки весов:

```bash
PYTHONPATH=. python scripts/bench_extract.py --model artifacts/models/fusion \
  --images dataset/images --csv splits/fold0_query.csv --device cuda:0 \
  --require-cuda --warmup 50 --iterations 300 --batch-sizes 1,8,16,32 \
  --throughput-seconds 10 --json-out outputs/bench.json
```

Запас относительно 100 FPS небольшой. Итоговую скорость определяет запуск на оборудовании жюри.

## Воспроизводимость

Финальные выходы: [валидация формата и SHA](evidence/output_validation.json), [сравнение повторных запусков](evidence/determinism.json). Проверки выполнены 27 сентября; два дополнительных запуска публичной сборки 28 сентября также совпали с каноническими файлами. Это исторические результаты конкретного окружения, не заявление о новой GPU-проверке после изменения документации.

Для проверки сохранённых результатов:

```bash
PYTHONPATH=. python -m reid.eval.validate_outputs \
  --query dataset/test_query.csv --gallery dataset/test_gallery.csv \
  --submission submission/submission.csv --embeddings submission/embeddings.npy \
  --candidates submission/candidates.csv
```

C6 проверяет формат, а не качество распознавания. Видео показывает готовый Docker-образ, офлайн-запуск и проверку трёх файлов на демонстрационном наборе; оно не является бенчмарком.

## Независимость запросов и ограничения

[Замена соседей и перестановка](evidence/query_content.json) при batch=32 сохранили результаты восьми фиксированных запросов побитово. [Сравнение batch=1 и пакетного запуска](evidence/query_independence.json) на 24 запросах сохранило top-10, кандидатов и отказы, но confidence отличался до **0.000393**: строгая численная проверка осталась **FAIL**. Код не использует информацию других query; универсальное побитовое совпадение при разных формах батча не доказано.

Геометрическая заливка номерной области использовалась при обучении и контрольном запуске, но может промахиваться мимо настоящего номера. Устойчивость при заливке точных номерных зон не подтверждена. Отсутствие OCR само по себе её не доказывает.

Основные ошибки: одинаковая модель и оклейка, смена ракурса, ночь, перекрытия и потеря мелких деталей при уменьшении изображения. Примеры train/validation показаны в презентации. Когда в gallery нет cross-camera позитива, но остался снимок той же машины с той же камеры, confidence может быть завышен.

Официальный файл `extractor.py` не был предоставлен; текущий интерфейс — `Extractor.extract(image_path, bbox)` и `extract_batch(items)` в `reid/infer/extractor.py`.

Для большой gallery планируется ANN с проверкой потери качества на реальных данных. Эксперимент из презентации относится к миллиону синтетических 1536-мерных векторов, не к финальным 3072-мерным эмбеддингам: `scripts/analysis/ann_scale.py`.
